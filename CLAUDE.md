Proyecto RappiBellion

Descripción

RappiBellion es un proyecto en desarrollo que busca integrar funcionalidades de delivery y gestión de pedidos con un enfoque experimental. Este archivo CLAUDE.md sirve como guía inicial para configurar y trabajar con Claude Code en el repositorio.

Dependencias

Node.js v18 o superior

npm o yarn

Git

Ollama (para ejecución local de modelos)

Instalación

Clonar el repositorio:

git clone https://github.com/tuusuario/RappiBellion_Beta50890.git

Entrar en la carpeta del proyecto:

cd RappiBellion_Beta50890

Instalar dependencias:

npm install

Ejecución

Para levantar el servidor de desarrollo:

npm start

Estructura del proyecto

/src → Código fuente principal

/config → Archivos de configuración

/public → Recursos estáticos
